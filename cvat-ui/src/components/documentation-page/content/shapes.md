# 标注形状

CVAT 提供多种标注形状，适配不同的计算机视觉任务。本章介绍各类工具的用途与基本操作。

## 矩形框（Rectangle / Bounding Box）

最常用的标注类型，用于目标检测。

- **绘制**：选择矩形工具与标签，在画布上从一角拖到对角即可。
- **四点绘制**：「By 4 points」模式下依次点击对象的上、下、左、右四个极值点，自动生成外接矩形。

## 多边形（Polygon）

用于图像分割与不规则形状对象。

- 依次点击对象边界的各个顶点，按 **N** 完成绘制。
- 可启用智能工具辅助（如自动勾边）。
- 绘制后可拖动顶点微调，或在边上点击插入新顶点。

## 折线（Polyline）

用于标注道路、车道线等线状对象，绘制方式与多边形类似，但不闭合。

## 点（Points / 关键点）

用于姿态估计、关键点检测等。

- **单点**：标注独立的点。
- **点集 / 骨架（Skeleton）**：用于人体姿态等需要多个关联关键点的场景，可预先定义骨架模板。

## 长方体（Cuboid）

用于在 2D 图像上标注 3D 物体（如车辆），呈现透视立体框。绘制后可分别调整各个面与顶点。

## 椭圆（Ellipse）

用于圆形或椭圆形对象，绘制中心并拖动确定长短轴。

## 蒙版（Mask / 像素级分割）

用于实例分割，提供画笔、橡皮擦、多边形等子工具逐像素涂抹对象区域，
可设置画笔大小，并在完成后转换为多边形。

## 标签 / 标记（Tag）

不绘制几何形状，而是为 **整帧** 打上分类标签，适合图像分类任务。
使用 **标签标注工作区** 可快速为连续帧打标签。

## 常用绘制技巧

- 绘制过程中按住可临时切换为移动画布。
- 使用鼠标滚轮缩放，按住中键拖动平移。
- 绘制多边形/折线时，按 **Z** 撤销上一个点。
- 智能工具与自动标注可生成初始形状，再手动精修，显著提速。
