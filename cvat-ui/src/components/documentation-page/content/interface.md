# 界面导航

本章介绍 CVAT 主界面与标注编辑器的主要区域。

## 顶部导航栏

登录后顶部导航栏提供以下入口：

- **项目（Projects）**：管理项目及其下属任务。
- **任务（Tasks）**：创建与管理标注任务。
- **作业（Jobs）**：查看分配给你的所有作业。
- **请求（Requests）**：查看导入/导出等后台任务的进度。
- **模型（Models）**：管理用于自动标注的模型。

右上角包含：

- **问号图标**：打开本中文使用指南。
- **用户菜单**：组织管理、设置、个人资料、退出登录等。

## 任务列表页

任务列表以卡片形式展示每个任务，显示名称、状态、作业数量等。可使用顶部搜索与筛选器快速定位任务，
点击任务卡片进入详情页，查看其作业列表与操作菜单（导出、备份、自动标注等）。

## 标注编辑器

进入某个作业后即进入标注编辑器，主要区域包括：

| 区域 | 说明 |
| --- | --- |
| 左侧控制栏 | 标注工具（光标、移动、矩形、多边形、折线、点、长方体、蒙版等）。 |
| 顶部菜单栏 | 保存、撤销/重做、作业状态、菜单（导出/导入标注等）。 |
| 中央画布 | 显示当前帧并进行标注的工作区。 |
| 右侧对象栏 | 当前帧/作业中的标注对象列表与属性编辑。 |
| 底部播放条 | 帧导航、播放、跳转、上一帧/下一帧。 |

## 工作区模式

标注编辑器提供多种工作区：

- **标准工作区（Standard）**：默认模式，适合大多数标注任务。
- **属性标注（Attribute annotation）**：聚焦逐个对象快速编辑属性。
- **标签标注（Tag annotation）**：为整帧打分类标签。
- **审核（Review）**：审核人员为标注添加问题（Issue）与评论。

可在画布右上角切换工作区模式。

## 设置

通过用户菜单中的 **设置（Settings）** 可调整播放器、工作区、快捷方式等偏好，例如帧跳转步长、
显示对象详情、自动保存间隔等。
