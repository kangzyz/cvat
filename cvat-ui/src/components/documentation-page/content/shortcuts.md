# 快捷键

熟练使用快捷键可显著提升标注效率。下表为标注编辑器中的常用默认快捷键，
完整且可自定义的列表可在标注界面按 **F1** 打开。

## 通用

| 快捷键 | 功能 |
| --- | --- |
| F1 | 打开快捷键帮助 |
| F2 | 打开设置 |
| Ctrl\+S | 保存标注 |
| Ctrl\+Z | 撤销 |
| Ctrl\+Shift\+Z / Ctrl\+Y | 重做 |

## 帧导航

| 快捷键 | 功能 |
| --- | --- |
| F | 下一帧 |
| D | 上一帧 |
| V | 向前快进若干帧 |
| C | 向后快退若干帧 |
| Space | 播放 / 暂停 |
| Ctrl\+Home | 跳到第一帧 |
| Ctrl\+End | 跳到最后一帧 |

## 标注操作

| 快捷键 | 功能 |
| --- | --- |
| N | 开始 / 结束绘制当前形状 |
| Esc | 取消当前绘制或选择 |
| Delete | 删除选中对象 |
| Shift\+Delete | 强制删除（含锁定/轨迹） |
| Ctrl\+C / Ctrl\+V | 复制 / 粘贴对象 |
| Ctrl\+B | 向后续帧传播对象 |
| L | 锁定 / 解锁对象 |
| H | 隐藏 / 显示对象 |
| Q / Num\+/- | 切换对象遮挡（occluded） |

## 画布操作

| 快捷键 | 功能 |
| --- | --- |
| 鼠标滚轮 | 缩放 |
| 按住中键拖动 | 平移画布 |
| F | 适配窗口（部分模式） |
| Z | 绘制多边形/折线时撤销上一个点 |

> 以上为默认配置。可在 **设置 → 快捷方式** 中自定义按键绑定；不同工作区可能有专属快捷键。
