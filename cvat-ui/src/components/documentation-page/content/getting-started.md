# 快速开始

本章带你完成从登录到导出标注结果的完整流程。如果还没有搭建 CVAT，请先阅读 **安装部署** 一章。

## 1. 登录

在浏览器中打开 CVAT 服务地址（本地部署默认为 `http://localhost:8080`）。
社区自托管环境中，公开注册默认关闭，用户由管理员创建。使用管理员分配的账号密码登录即可。

> 管理员可通过命令 `docker exec -it cvat_server bash -ic 'python3 ~/manage.py createsuperuser'` 创建超级用户。

## 2. 创建标注任务

1. 进入顶部导航的 **任务（Tasks）** 页面，点击 **\+** 或 **创建新任务**。
2. 填写任务名称。
3. 添加 **标签（Labels）**：点击「添加标签」，输入类别名称（如 `car`、`person`），可设置颜色与属性。
4. 在 **选择文件** 区域上传待标注的图像或视频，也可以从已连接的共享存储、远程 URL 中选择。
5. 如需将任务拆分为多个作业，可在 **高级配置** 中设置「片段大小（Segment size）」。
6. 点击 **提交并打开**，等待数据处理完成。

## 3. 开始标注

1. 在任务详情页点击某个作业（Job）进入标注编辑器。
2. 在左侧控制栏选择标注工具（如矩形框）。
3. 在弹出的对话框中选择标签和绘制方式，然后在图像上绘制标注。
4. 使用底部播放条在视频/图像序列的不同帧之间切换。
5. 标注完成后，注意 **保存（Ctrl\+S）**。

更多绘制技巧见 **手动标注** 与 **标注形状** 章节。

## 4. 修改作业状态

标注完成后，可在标注界面顶部将作业状态从 **进行中（in progress）** 改为 **已完成（completed）**，
便于审核人员跟踪进度。

## 5. 导出标注结果

1. 回到任务详情页，点击右上角菜单中的 **导出任务数据集（Export task dataset）**。
2. 选择导出格式（如 COCO、YOLO、Pascal VOC、CVAT for images 等）。
3. 选择是否包含图像数据，点击确定后下载结果压缩包。

至此你已完成一个完整的标注循环。后续可结合 **自动标注** 进一步提升效率。
