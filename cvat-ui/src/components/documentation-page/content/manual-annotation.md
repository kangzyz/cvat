# 手动标注

手动标注是 CVAT 最基础的工作方式。本章介绍标注的通用流程与两种标注对象类型。

## 形状（Shape）与轨迹（Track）

- **形状（Shape）**：只存在于单帧，适合标注图像或视频中静止/独立出现的对象。
- **轨迹（Track）**：跨多帧存在，CVAT 会在关键帧之间 **自动插值**，适合视频中的目标跟踪。
  只需在若干关键帧调整对象位置，中间帧自动生成。

绘制时可在工具对话框中选择「Shape」或「Track」模式。

## 通用绘制流程

1. 在左侧控制栏点击某个标注工具（如矩形）。
2. 在弹出的对话框中选择 **标签** 与 **绘制方式**。
3. 点击 **Shape** 或 **Track** 进入绘制状态。
4. 在画布上绘制对象。
5. 重复以上步骤标注更多对象，完成后按 **Ctrl\+S** 保存。

## 编辑标注

- **选择对象**：用光标点击标注或在右侧对象列表中选择。
- **移动 / 缩放**：拖动对象或其控制点。
- **修改标签**：在右侧对象栏的下拉中切换标签。
- **删除对象**：选中后按 **Delete**（轨迹按 **Shift\+Delete** 强制删除）。
- **锁定 / 隐藏**：在对象栏中锁定防止误改，或隐藏以减少干扰。

## 关键帧与插值（轨迹）

对于轨迹对象：

- 在某帧调整对象位置后，该帧会成为 **关键帧**。
- CVAT 在相邻关键帧之间线性插值，生成中间帧位置。
- 当对象暂时离开画面时，可将其标记为 **outside（画面外）**，跟踪在该段暂停。

## 属性标注

若标签定义了属性（如 `car` 的颜色、是否遮挡），可在右侧对象栏为对象设置属性值。
使用 **属性标注工作区** 可逐个对象快速填写属性，提高效率。

## 复制与传播

- **复制/粘贴对象**：使用 **Ctrl\+C / Ctrl\+V**。
- **传播（Propagate）**：将当前对象复制到后续若干帧，适合静止对象的批量标注（快捷键 **Ctrl\+B**）。

更多具体工具用法见 **标注形状** 章节。
