# 项目与任务管理

CVAT 通过 **项目 → 任务 → 作业** 三层结构组织标注工作。

## 项目（Project）

项目用于管理共享同一套标签体系的多个任务。在项目层级定义标签后，
其下所有任务都会继承这些标签，便于大规模数据集保持标注一致性。

**创建项目：**

1. 进入 **项目** 页面，点击 **\+ 创建新项目**。
2. 填写项目名称并定义标签。
3. 创建任务时在「项目」下拉中选择该项目，即可继承其标签。

## 任务（Task）

任务是一批待标注的图像或视频。创建任务的关键选项：

- **名称**：任务标识。
- **标签**：若未关联项目则需在此定义。
- **选择文件**：可上传本地文件、从共享存储选择、或填写远程 URL / 云存储。
- **高级配置**：
  - **片段大小（Segment size）**：将任务拆分为多个作业，每个作业包含指定数量的帧。
  - **重叠大小（Overlap size）**：相邻作业之间重叠的帧数，便于跟踪连续性。
  - **图像质量（Image quality）**：内部使用的压缩质量。
  - **起止帧、帧步长**：控制实际参与标注的帧范围。

## 作业（Job）

任务按片段大小拆分为多个作业，作业是分配给标注员的最小工作单元。
在任务详情页可以：

- 查看每个作业的状态（新建 / 进行中 / 已完成）与阶段（标注 / 审核 / 验收）。
- 将作业 **分配（Assignee）** 给具体用户。
- 点击作业进入标注编辑器开始工作。

## 任务操作菜单

任务详情页的操作菜单包含：

- **导出任务数据集**：按所选格式导出标注。
- **导入标注**：上传已有标注文件。
- **备份任务**：导出包含数据与标注的完整备份。
- **自动标注**：使用模型进行预标注。
- **移动到项目**：将任务归入某个项目。
- **删除任务**。

## 组织与协作

通过用户菜单中的 **组织（Organization）** 可创建团队，邀请成员并分配角色（Owner / Maintainer / Supervisor / Worker），
实现多人协同标注与审核。组织内的项目、任务对成员可见。
