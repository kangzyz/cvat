# CVAT 概述

CVAT（Computer Vision Annotation Tool，计算机视觉标注工具）是一款开源的图像与视频标注平台，
广泛用于为计算机视觉算法准备训练数据。本指南为 **社区版（自托管）** 中文文档，
聚焦本地部署即可使用的功能。

## CVAT 能做什么

- **图像与视频标注**：支持矩形框、多边形、折线、关键点、长方体、椭圆、蒙版等多种标注类型。
- **多种任务模式**：目标检测、图像分割、姿态估计、目标跟踪等。
- **团队协作**：可创建组织、分配任务与作业（Job），多人协同标注与审核。
- **自动标注**：接入深度学习模型（如本地部署的 YOLO）进行预标注，再人工修正，显著提升效率。
- **丰富的数据格式**：支持导入/导出 COCO、Pascal VOC、YOLO、CVAT、Datumaro 等主流格式。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 项目（Project） | 一组共享标签体系的任务集合，便于统一管理标签。 |
| 任务（Task） | 一批待标注的图像或视频，是组织标注工作的基本单位。 |
| 作业（Job） | 任务按段（segment）拆分后的工作单元，可分配给不同标注员。 |
| 标签（Label） | 标注对象的类别，可附带属性（Attribute）。 |
| 形状（Shape） | 单帧上的标注，如一个矩形框。 |
| 轨迹（Track） | 跨多帧的标注，用于视频中的目标跟踪。 |
