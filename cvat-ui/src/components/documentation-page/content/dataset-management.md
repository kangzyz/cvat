# 数据集管理

CVAT 支持以多种主流格式导入和导出标注，并可对任务/项目进行完整备份。

## 支持的数据格式

| 格式 | 典型用途 |
| --- | --- |
| CVAT for images / video | CVAT 原生 XML 格式 |
| COCO | 目标检测、实例分割 |
| Pascal VOC | 目标检测 |
| YOLO | 目标检测（txt 标签） |
| Datumaro | CVAT 通用数据集框架，支持格式转换 |
| ImageNet | 图像分类 |
| Cityscapes | 语义分割 |
| Segmentation mask | 语义分割掩码 |

> 不同格式对标注类型的支持范围不同（如 YOLO 仅支持矩形框）。导出前请确认目标格式兼容你使用的形状。

## 导出标注 / 数据集

1. 在任务或项目详情页打开操作菜单，选择 **导出数据集（Export dataset）**。
2. 选择导出格式。
3. 勾选 **包含图像（Save images）** 可同时导出原图，否则仅导出标注。
4. 可选择直接下载或导出到已连接的云存储。
5. 在 **请求（Requests）** 页面查看导出进度并下载结果。

## 导入标注

1. 在任务详情页操作菜单选择 **导入标注（Import annotations）**。
2. 选择与文件匹配的格式并上传文件。
3. 确认是否覆盖已有标注。

> 导入文件的标签名称需与任务中的标签对应，否则可能被忽略。

## 备份与恢复

备份包含数据、标注与任务配置，可用于迁移或归档。

- **创建备份**：在任务/项目操作菜单选择 **备份（Backup）**，下载 `.zip`。
- **从备份恢复**：在任务或项目列表页选择 **从备份创建（Create from backup）**，上传备份文件。

项目备份会包含其下所有任务，无需逐个导出。

## 迁移整套 CVAT 数据

如需将整个 CVAT 实例迁移到另一台机器，应备份 Docker 数据卷：

- `cvat_db`：PostgreSQL 数据库（存放标注与元数据）。
- `cvat_data`：上传的图像/视频数据。

在新机器上恢复这些卷后重新 `docker compose up -d` 即可。
